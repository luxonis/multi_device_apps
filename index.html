Detection filters

Filters apply to the panorama and each source view. Label IDs are comma separated. Off keeps duplicates; NMS chooses one; Average merges them across cameras in the panorama.

Install the updated DepthAI wheel for Detections; see USAGE.md.

Capture

Saves to captures/, after the PTP frame lock. Frames: the calibration material, the same number of synchronized full-resolution image groups the calibration collects from the cameras chosen under each device, plus the factory calibration of every device. Point cloud: one merged point cloud of the selected stereo devices in the calibration origin as PLY, plus every device's cloud (needs a calibration).
